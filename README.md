# 見下ろし視点 2D キャラクター歩行デモ

8列 x 4行 (下 / 上 / 右 / 左) のスプライトシートで、キャラクターが 4方向に歩ける
最小構成のデモです。HTML5 Canvas と素の JavaScript だけで動き、ビルド手順はありません。

## 動かす

`index.html` をブラウザで直接開くだけで動きます。

ローカルサーバ経由で開きたい場合:

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

### 操作

| キー | 動作 |
| --- | --- |
| 矢印キー / WASD | 移動 (斜め移動あり) |
| F1 | デバッグ表示 (fps / 座標 / 当たり判定) |

## スプライトシートの差し替え

`assets/character.png` は**仮の素材**です。ご提示いただいた画像はチャット上の画像で
リポジトリには取り込めなかったため、同じ並び (8列 x 4行 / 下・上・右・左) の
プレースホルダを `tools/make_placeholder_sheet.py` で生成しています。

本物の素材に差し替える手順は次のとおりです。

### 1. 罫線付きの参考画像から切り出す

ご提示の画像のように、行見出し (下/上/右/左)・列見出し (1〜8)・黒い罫線が
入ったままだとゲームには使えません。付属のスクリプトで罫線を検出し、
マスの中身だけを隙間なく並べ直したシートを書き出せます。

```sh
pip install pillow
python3 tools/slice_reference_sheet.py 参考画像.png -o assets/character.png
```

- 背景は自動で透明化します (外周から届く背景色だけを塗りつぶし式に消すので、
  輪郭線で囲まれたドレスの内側などは残ります)。
- キャラの色が背景と近すぎて消えすぎた場合は `--tolerance` を下げてください
  (既定 12)。消えすぎたときは警告が出ます。
- 罫線の自動検出に失敗したら、マスの位置を直接指定できます:

  ```sh
  python3 tools/slice_reference_sheet.py 参考画像.png \
      --x0 45 --y0 30 --cell-w 117 --cell-h 133
  ```

### 2. 必要なら設定を直す

1コマのサイズは画像サイズから自動計算する (`幅 / 8`, `高さ / 4`) ので、
素材の解像度が変わってもコードを直す必要はありません。

行の並びやアニメ速度を変えたいときは `src/config.js` だけ触れば済みます。

```js
rowOf: { down: 0, up: 1, right: 2, left: 3 },  // 行の並び
idleFrame: 0,     // 立ち止まったときに表示するコマ
walkFps: 10,      // 歩行アニメの速さ
speed: 90,        // 移動速度 (px/秒)
```

立ち絵が不自然なときは `idleFrame` を調整してください
(1コマ目が直立ポーズでない素材もあります)。

## ファイル構成

```
index.html                       画面と読み込み
src/config.js                    スプライトシートと挙動の設定 (基本ここだけ触る)
src/input.js                     キー入力
src/sprite.js                    シートの切り出しとコマ送り
src/world.js                     タイルマップと当たり判定
src/camera.js                    追従カメラ
src/player.js                    移動・向き・アニメ
src/main.js                      起動とメインループ
assets/character.png             スプライトシート (現状は仮素材)
tools/slice_reference_sheet.py   罫線付き参考画像 → スプライトシート
tools/make_placeholder_sheet.py  仮素材の生成
```

## 実装メモ

- **足元基準の座標**: プレイヤーの `x, y` は足元の中心。見下ろし視点では
  当たり判定と重なり順を素直に扱えます。
- **当たり判定は足元だけ**: 見た目の矩形全体ではなく足元の小さな矩形で判定します
  (頭が木に重なっても通れる、という見下ろし視点の定番の挙動)。
- **軸ごとの移動**: X と Y を別々に判定するので、壁に斜めからぶつかっても
  止まらず壁沿いに滑ります。
- **斜め移動の正規化**: 斜めでも速度が 1.41 倍にならないようにしています。
- **斜めのときの向き**: 後から押したキーの軸を向きます。
- **ドット絵の描画**: `imageSmoothingEnabled = false` と整数倍スケール、
  カメラ座標の丸めで、拡大してもぼやけ・ちらつきが出ないようにしています。

## 動作確認

Chromium (Playwright) で以下を確認済みです。

- 4方向の移動と向きの切り替え
- 歩行アニメが 8コマ循環し、停止で `idleFrame` に戻る
- 斜め移動の速度が正規化されている (0.3秒で約 28px ≒ 90px/秒)
- 壁に向かって歩くと壁の手前で止まる
